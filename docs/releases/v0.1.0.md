# v0.1.0 — Local PostgreSQL Foundation

Status: draft. Publish after the foundation PR is merged and CI passes on `main`.

## Summary

The Local PostgreSQL Foundation provides a reproducible database deployment and
verifies that complete order records survive container recreation on a retained
volume.

## Highlights

- PostgreSQL 17.11 image pinned to an immutable digest.
- Persistent database volume, data page checksums, and validated order schema.
- Generated local password outside Git and no published database port.
- Isolated acceptance scenario with exact record comparison and a new write
  after container recreation.
- Pull-request CI configured to run static checks and database acceptance.

## Validation

`make check` and `make acceptance` passed locally. The scenario retained all
fields of 20 orders, rejected a negative amount, and accepted a new order after
recreation. Repeated password setup preserved the existing file with mode `0600`
and Git exclusion.

See the [local acceptance evidence](../../evidence/local-foundation-acceptance-20260924.md).
Remote CI remains required before publication.

## Scope And Interpretation

This release establishes the local database foundation. Backup restoration,
point-in-time recovery, replication, and RPO/RTO measurement remain outside
its verified scope.
